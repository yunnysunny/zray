## 断网缺陷

0.3.0-2 的默认故障策略为 block。失败规则还拒绝路由器自身的公网 IPv4，可能阻止后续恢复所需的 DNS、探测及访问。停止服务、删除规则和恢复 DNS 之间存在提前返回：前一步失败可导致后续恢复未执行。启动检测另有硬编码地址，忽略配置的 probe_url。

0.3.0-3 修复：
- 默认故障策略 direct；新增断网保护时要求界面单独确认。
- 显式断网保护仅作用于所选 LAN 设备，不阻断路由器自身恢复连接。
- 故障直连不保留 IPv6 拒绝规则。
- 关闭、失败清理分步执行；前一步失败不跳过 DNS 恢复；保留所有错误与最终状态。
- 保存 DNS 转发的 server/noresolv/resolvfile 字段并恢复，不覆盖 DHCP 地址池等其他配置；所有恢复步骤成功后才删除备份。
- 启动检测使用配置的 probe_url。
