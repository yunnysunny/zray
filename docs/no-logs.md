# 低存储运行约定

从 0.3.0-13 起，Zray 不保存历史日志。

- 主代理、独立 DoH 和健康监控的 procd stdout/stderr 捕获均关闭，不把其输出交给 logd。
- 配置任务、后台检测丢弃终端输出；不再调用 logger、不追加日志、不轮转日志。
- 健康检查和节点检测的失败原因通过管道即时处理，不写错误日志。节点临时配置改放 /tmp，正常结束即清理。
- 订阅临时正文在成功或失败时清理，不保存下载错误日志。
- 升级时仅删除本插件已知的旧日志文件和遗留下载正文。不清空路由器共享的系统日志，不删除其他服务的数据。
- 移除历史日志 RPC、权限和 UI。诊断仅展示当前资源和当前错误。
- 代理关闭或全部直连时，不启动健康监控常驻进程。

## 内存边界

没有日志不代表程序可以零内存运行。开启代理所需的进程、连接缓冲、必要配置、DNS 恢复备份与当前状态仍需存在。

当前状态采用覆盖写而不是追加：设置错误上限 1024 字符，健康错误上限 512 字符；资源快照只保留一份。/tmp 通常使用 RAM，因此也禁止在 /tmp 累积日志。关闭代理后无 Zray 代理、DNS 或健康监控常驻进程；系统页缓存与 LuCI/rpcd 本身的资源不属于零占用保证。

## 验证

- 20 项 Node 测试通过，包括无文件日志、关闭 procd 捕获、无历史日志 RPC、关闭时不启动健康监控等约束。
- 21 个 ucode 源文件/入口编译检查与 59 项既有 ucode 回归断言通过。
- 实机安装后：代理关闭、原节点保留、Zray 常驻进程计数为 0；资源接口 logging.enabled=false，retained_files=0。
- 独立节点检测成功，耗时 1475ms；检测后 retained_files 仍为 0。
- 此次未对正在工作的网络注入故障；未宣称代理启用后的长期物理内存使用完全恒定。
