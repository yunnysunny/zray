# Zray 0.3 控制界面

## 分流和设备范围

“网络与恢复设置”提供全局代理、规则分流（默认直连）、全部直连。IP/CIDR 和域名列表分别指定直连与代理目标，代理列表优先。局域网和节点服务器地址保持直连。

设备范围可选择全部 LAN 设备或指定 MAC；可从当前 DHCP 租约列表添加设备。静态地址设备可手动填写 MAC。这里只控制配置的 LAN 接口。

域名分流需要 DNS 查询经过路由器，以及支持 nftset 的 dnsmasq-full。保存前检查此能力，不满足时拒绝域名规则并保留原设置。客户端自行使用 DoH 时，域名分流不能保证生效。无需域名分流时不要求更换 DNS 软件包。

IPv6 可保持直连或阻断所选设备的公网 IPv6。IPv6 隧道和 UDP 透明代理不在支持范围。界面会提示 IPv6 直连的绕过风险。

## 连通状态与故障恢复

资源面板把服务状态和连通状态分别显示。后台默认每 60 秒检测一次 HTTPS 代理请求和本机 DNS 查询，连续三次失败后执行恢复，恢复操作至少间隔 120 秒。检测间隔、失败次数和冷却时间均可调整。

无备用节点时，重新解析并启动当前节点。设置备用节点后，按列表选择其他节点。代理可用但 DNS 查询失败时，切换主要/备用 DoH 并重新应用。

主开关代表用户期望状态。启用失败时保留期望状态、显示错误，后台可继续恢复。故障默认恢复直连；只有用户明确选择并确认“断网保护”才会阻断所选设备的公网 IPv4。故障阻断不得影响路由器自身的 DNS、检测、下载或恢复连接。清理规则、停止代理 DNS、恢复原 DNS 各自执行，一个步骤失败不会跳过后续恢复。启用前保存 DNS 转发字段；恢复时只还原这些字段，不覆盖 DHCP 地址池和其他设置。关闭主开关会清理转发和阻断规则，并恢复原 DNS。管理界面和内网访问不受故障阻断影响。

## 资源面板

展示 CPU、可用内存、闪存余量、Zray 物理内存、系统连接数和 LAN 双向流量，约每 5 秒采样。LAN 速率包括非代理流量；系统连接数不是 Zray 活动连接数。首次采样尚无差分数据时显示“等待采样”。

## 节点维护

节点列表支持搜索、单节点 HTTPS 检测和串行批量检测。测试临时启动独立的低连接数实例，不切换正在使用的节点。

支持手动下载 HTTPS 订阅：验证整批 VLESS + REALITY 节点后合并，保留已有节点。暂不提供定时订阅更新。订阅限制为公网 HTTPS、443 端口、不跟随重定向、256 KiB、最多 256 个节点。

节点备份使用带版本号的 JSON，可导入合并。导出前会提示凭据风险。诊断导出不包含节点 UUID、公钥、分享链接或订阅地址。

## 低存储运行和权限

从 0.3.0-13 起不保存历史日志，procd 不采集插件的 stdout/stderr；设置任务与后台检测不写文件日志或 logger。错误只保留当前一条、有长度上限的状态；旧的插件私有日志会在升级时删除。必要的原 DNS 恢复备份仍保留，资源快照覆盖写。关闭代理时不常驻健康监控进程。详见 [低存储运行约定](no-logs.md)。

各项 RPC 使用专用 ACL，节点测试、订阅下载和修改设置仅授予写权限。无通用命令执行或任意文件访问接口。

## 开发验证

`npm test` 检查链接和界面基础契约。
`python3 tools/check_ucode.py --ucode /path/to/ucode` 编译全部 ucode 文件，并执行真实 ucode 策略测试。
编译检查对 uci/ubus 等平台模块使用动态链接标记，仅检查语法，不代表 OpenWrt 集成通过。
部署前仍需验证真实 nftables、DNS、节点检测、启停清理、故障恢复及升级保留设置。
